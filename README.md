# ItzFallenMe portfolio (Next.js + TSX)

## Local development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Content
- Edit portfolio content in `lib/site.ts` (bio, projects, experience, skills, achievements).
- Blog posts are in `lib/blog.ts`.
- Project detail routes are generated from the project list.
- The Wall is a browser-local demo; notes are not shared with other visitors.

## Contact form
By default, the contact form opens the visitor's email application with the message prefilled. To enable a hosted form endpoint, add `NEXT_PUBLIC_FORMSPREE_ENDPOINT` to the build environment (for example, a Formspree endpoint). The form will then submit to that endpoint and show status feedback. Configure the endpoint with the provider before deploying.

## RSS feed
Set `NEXT_PUBLIC_SITE_URL` to the canonical deployed URL at build time so the RSS feed emits correct absolute links. If unset, feed links are left blank rather than inventing a deployment URL.

## Discord presence
Discord presence uses Lanyard. Join the Lanyard Discord with the tracked account if the widget does not show presence.

## Deployment
This project uses Next.js static export (`output: "export"`). Static hosting is suitable for the portfolio pages, project/blog routes, and local Wall demo. Features requiring server-side processing should use a configured external service.

## Optional shared Wall (Supabase)

The Wall defaults to local browser storage. To enable a shared public wall, configure `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`, then create the table and policies below in Supabase SQL Editor. This makes notes publicly readable and insertable; add moderation/rate-limiting before enabling on a public site.

```sql
create table public.wall_notes (
  id bigint generated by default as identity primary key,
  text varchar(180) not null,
  color text not null,
  rotation smallint not null default 0,
  created_at timestamptz not null default now()
);
alter table public.wall_notes enable row level security;
create policy "Anyone can read wall notes" on public.wall_notes for select to anon using (true);
create policy "Anyone can pin wall notes" on public.wall_notes for insert to anon with check (true);
grant select, insert on public.wall_notes to anon;
grant usage, select on sequence public.wall_notes_id_seq to anon;
```
